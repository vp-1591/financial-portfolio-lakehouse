- (decision) AD-1 One raw Delta table per broker; source discriminates data kind. Binds: CAP-1, raw layer, all connectors. Prevents: per-broker x per-layer raw multiplicity (raw/{broker}_snapshot + raw/{broker}_events) and a global single bronze returning. - (decision) AD-2 The source vocabulary is a per-broker routing contract, defined once. Binds: CAP-1, CAP-3, fetch writers, transform readers. Prevents: fetch and transform drifting on source strings; each transform re-deriving its own substring heuristics. Rule: each broker module owns its source vocabulary (IBKR 'flex'/'flex_events'; T212 the 5 API paths; XTB 'XTB_REPORT'); fetch writes with it and transforms route on it; transforms test membership in the declared set (exact or prefix-anchored), never free substring matching.
- (decision) AD-3 Events transforms gate on source BEFORE payload unwrapping. Binds: CAP-3, per-broker transform_events. Prevents: a bare-JSON-list snapshot payload (T212 /equity/positions) being treated as events - the core data-integrity failure this feature exists to make impossible. Rule: transform_events include-filters rows to the broker's event-source set first; only gated rows are unwrapped/parsed; a row outside the set can never produce an event row.
- (decision) AD-4 Snapshot transform consumes snapshot sources; filter_latest_snapshot stays PER-SOURCE. Binds: CAP-3, transform_utils, transform_snapshot. - (decision) AD-5 Fetch writes rows to the single table; only the write target merges. Binds: CAP-1, CAP-2, per-broker fetch_*. Prevents: API calls being merged or per-layer write plumbing reappearing. Rule: each fetch kind appends its own rows (each row tagged with its source) to raw/{broker}; per-endpoint try/except write-what-succeeded isolation stays; T212's all-events-endpoints-empty RuntimeError (fetch.py:121) survives unchanged; IBKR's two Flex queries and T212's five endpoints remain separate fetches.
